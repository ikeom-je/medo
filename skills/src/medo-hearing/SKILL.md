# medo-hearing:(medo-investigate に統合済み)

ヒアリングは標準周回のステージ1「調べる・仕立てる」の一部になった。

**`medo-investigate` を使う**。ヒアリングで課題と方針を構造化し、出典付きファクトを保存し、必要なら現状調査・分析報告書と討議用スライドまで作る手順がそこにある。

このSkillは移行期間中のポインタであり、統合完了後に削除する。
